# Self-Evolving AI on FPGA

A research project to build a self-evolving AI system 
on Xilinx Zynq 7020 (Moku:Go), featuring multi-evaluator 
architecture and constitutional audit structure.

## Overview

This project explores whether an evolutionary system 
equipped with multiple evaluators and an audit structure 
demonstrates greater generalization and robustness than 
systems driven by a single fixed evaluation function.
